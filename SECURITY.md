# Segurança

Este projeto distribui apenas arquivos de localização para uma tradução de fã. A release não contém executáveis, DLLs, instaladores ou o jogo completo.

Baixe os arquivos somente pelas releases do GitHub e confira o SHA-256 publicado em `SHA256SUMS.txt`. Problemas de segurança podem ser relatados ao mantenedor por meio das ferramentas privadas do GitHub.
