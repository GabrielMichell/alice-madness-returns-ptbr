# Alice: Madness Returns — Tradução PT-BR

Tradução de fã para português brasileiro de **Alice: Madness Returns** na versão Steam.

## Download

Baixe `Alice-Madness-Returns-PTBR-v1.0.0.zip` na página de [releases](https://github.com/GabrielMichell/alice-madness-returns-ptbr/releases).

O pacote contém somente os arquivos localizados e não inclui o jogo, executáveis ou instaladores.

## Instalação manual

1. Feche o jogo.
2. Faça backup da pasta `AliceGame` original.
3. Extraia o ZIP na pasta principal do jogo, preservando a pasta `AliceGame`:

   `C:\Program Files (x86)\Steam\steamapps\common\Alice Madness Returns`

4. Inicie o jogo com o idioma inglês selecionado na Steam.

O conteúdo de `AliceGame` do ZIP deve ser mesclado com o `AliceGame` existente. A Central PT-BR cria seu próprio backup antes da instalação e permite remover a tradução pelo aplicativo.

## Conteúdo localizado

- menus, opções, avisos e textos de interface;
- textos de jogo e memórias;
- legendas de diálogos;
- fonte necessária para exibir caracteres do português brasileiro.

A versão revisada contém 266 arquivos prontos para instalação: 96 arquivos de localização e 170 pacotes binários `CookedPC` usados pelas legendas de diálogos e pela fonte.

## Compatibilidade

- Plataforma: Steam.
- AppID Steam: `19680`.
- Pasta detectada: `Alice Madness Returns`.
- Executável: `Binaries\Win32\AliceMadnessReturns.exe`.

## Central PT-BR

Após a publicação, esta tradução será cadastrada na [Central PT-BR](https://github.com/GabrielMichell/central-pt-br), que valida o SHA-256, cria backup e instala os arquivos sem executar instaladores externos.
